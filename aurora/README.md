# 🎓 Aurora University - Multi-Page Website

A responsive 6-page university website built using **HTML5, CSS3 and JavaScript** (no frameworks).
> Educational project - fictional university. No data is stored or sent anywhere.

## Pages
| Page | File | Highlights |
|------|------|-----------|
| Home | `index.html` | Live admission countdown, announcement ticker, featured courses, animated counters |
| Courses | `courses.html` | Search + level + department filters, details pop-up, personality-based Course Finder quiz |
| Admissions | `admissions.html` | Fee and scholarship calculator, eligibility check, validated application form |
| Campus Life | `campus.html` | Facility tabs, interactive events calendar, upcoming events, SGPA calculator |
| Placements | `placements.html` | Animated bar chart (average / highest), recruiter ticker, department results, stories slider |
| Contact | `contact.html` | Enquiry form, searchable department directory, FAQ accordion |

## Concepts used
- **HTML:** semantic tags, forms and input types (`date`, `tel`, `email`, `search`, `radio`, `checkbox`), tables, attributes, multi-page linking
- **CSS:** variables, Flexbox, Grid, transitions, animations, `:has()` selector, media queries, dark mode
- **JavaScript:** arrays/objects, loops, functions, conditions, DOM manipulation, events, `Date`, `setInterval`/`setTimeout`, regex validation, `filter`/`map`/`sort`/`reduce`, `URLSearchParams`, `localStorage` (theme)

## Run locally
Download or clone the repo and open `index.html` in a browser.
